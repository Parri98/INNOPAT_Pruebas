# INNOPAT · La Cartuja — Release v2.0.0

Esta release fija la **Versión 2** del prototipo.

Funciones principales:
- PWA responsive y accesible.
- 11 hitos.
- Listado accesible.
- Plano SVG conceptual.
- Google Maps preparado para 11 marcadores.
- Geolocalización opcional del visitante.
- Lector QR con cámara.
- Códigos QR de prueba H01–H11.
- Progreso de visita local.
- Estructura preparada para OpenCms.

No se consideran definitivos:
- coordenadas de las 11 paradas;
- contenidos patrimoniales;
- API key/Map ID;
- vídeos, 3D, encuesta y plano final.
